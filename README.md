# Hugo House — Demo giao diện app phụ huynh

Bản **xem thử giao diện** (dữ liệu mẫu, KHÔNG phải dữ liệu thật của trường).
Build từ `phu-huynh/` của hệ thống nội bộ Hugo House. Mã nguồn đầy đủ nằm ở repo riêng (private).

Mở demo: **https://btbinh2710.github.io/hugohouse-demo/** → bấm **"Xem thử giao diện"**.
